# 0001: 로컬 PEL 검증 후 FedPGP 결합

- 결정일: 2026-08-14; 2026-08-28 회의에서 재요약
- 기록일: 2026-10-06
- 상태: 회의에서 채택한 결합 방향을 보존. 성능 목표와 필수 평가 범위는 2026-10-06 결정으로 갱신됨. 구현·성능 승인과 구별
- 근거: [회의 근거 R01–R06](../research/meeting-evidence.md)

## 문제와 결정
현행 목표는 [VAD 성능 목표와 PEL 검토 범위](0002-vad-performance-objective.md)와 [프로젝트 성능 정의](../README.md#현행-연구-목표와-성능-정의)를 따른다. 아래는 당시 회의의 문제와 결정이다.

신종 이상 탐지를 개선하기 위해 기존 Fed-WSVAD에 PEL4VAD 방식의 정상/이상 대조학습을 로컬 단위로 적용하고 FedPGP 방식과 결합한다. 먼저 로컬 모델 하나에서 실제 동작과 성능 유효성을 각각 검증한다.

FedAvg를 비교 기준으로 유지하며 FedProx와 FedDyn은 어블레이션 대상으로 기록한다. Scaffold 제외는 당시 우선순위이며 현재 코드의 기능 제거를 뜻하지 않는다. DSANet 등의 조사 후보는 이 결정으로 채택하지 않았다.

## 영향과 열린 항목
FedPGP는 현재 저장소에서 공유 가중치 평균과 로컬 어댑터 유지로 구성되므로 두 경로를 함께 검증한다. n_ctx 4/8/16은 자체 실험이 필요하며 모듈 위치와 패딩은 후속 안건이다. FedDyn은 현 CLI에 없다.

이 기록은 새로운 성능 결과, 종료 일정, 실증 달성 상태를 확정하지 않는다. 후속 회의에서 변경되면 원본을 연결해 상태와 변경 이유를 갱신한다.
