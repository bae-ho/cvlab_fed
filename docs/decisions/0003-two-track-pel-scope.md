# 0003: 독립 연구 트랙과 PEL 작업 경계

- 날짜: 2026-10-06
- 상태: 채택
- 근거: 사용자 명시 지시
- 관련: [성능 목표](0002-vad-performance-objective.md), [과거 결합 방향](0001-local-pel-fedpgp.md)

장기태 연구원은 Fed-WSVAD 집계를, 김배호 연구원은 CCTV 적용 및 PEL4VAD 결합을 독립적으로 연구한다. 사용자는 김배호 연구원의 모듈 적용점과 실험 설계를 지원한다. 가장 좋은 방법들의 통합은 각 트랙의 검증 이후 진행한다.

현재 PEL 작업에서는 집계 방식을 수정하지 않는다. 집계·서버 optimizer·공유/로컬 정책을 고정하고 PEL 전달 경로, 특징·손실·gradient 및 평가 조건을 검토한다. PEL flag 연결 문제를 다른 집계 방식 선택으로 우회하지 않는다.

지자체가 각 클라이언트라는 맥락을 유지하며 scene/event 두 분할과 PEL의 호환성을 검토한다. event 단일 클래스 로컬 조건을 다중 이벤트 원본 배치와 혼동하거나 클라이언트 데이터를 합쳐 해결하지 않는다. CCTV scene은 현재 준비되지 않았다는 구현 제한을 보존한다.

세부 변경 경계와 통합 인터페이스는 [두 트랙 작업 범위](../research/two-track-scope.md)를 따른다. 기존 집계 결과는 비교 배경으로 남기며 이번 결정으로 삭제하거나 최종 채택하지 않는다.
