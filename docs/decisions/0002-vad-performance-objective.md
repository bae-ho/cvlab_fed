# VAD 성능 목표와 PEL 검토 범위

- 날짜: 2026-10-06
- 상태: 채택
- 근거: 사용자 지시. 성능 목표의 원본은 [docs/README.md](../README.md#현행-연구-목표와-성능-정의).
- 관련 이전 결정: [로컬 PEL 검증 후 FedPGP 결합](0001-local-pel-fedpgp.md). 결합 방향은 보존하고 성능 목표와 필수 평가 범위를 갱신한다.

## 문제

과거 회의 자료와 첫 코드 분석은 미학습 이벤트 감지를 중심으로 논의했다. 사용자는 기존 PEL4VAD 및 Fed-WSVAD보다 높은 성능과 연합학습 VAD SOTA를 현재 목표로 지정했으며, 미학습 이벤트 검증을 요구하지 않았다. 단일 이벤트 실험만으로 PEL 결합을 기각하는 판단도 재검토해야 한다.

## 검토한 대안

| 대안 | 판단 |
| --- | --- |
| 미학습 이벤트 검증을 필수 성공 기준으로 유지 | 최신 사용자 목표와 불일치 |
| 단일 이벤트 실험 결과만으로 PEL 결합 폐기 | 원본의 다중 이벤트 학습 조건을 반영하지 못함 |
| 다중 이벤트와 의미 사전의 적용 조건을 먼저 정리 | 채택. 구체적인 실행 설계는 후속 작업 |

## 결정

- 현행 목표와 성능 정의는 기존 `docs/README.md`를 확장하여 한 곳에서 관리한다.
- 과거 PDF는 보존하고 `meeting-note/README.md`에서 현행 정의와의 관계를 설명한다.
- 원본 PEL의 다중 이벤트 학습과 지식 기반 텍스트 기준을 복원하는 방향을 우선 검토한다.
- 이벤트 클래스 수, 클래스별 의미 표현 수, 배치 내 대조 후보 수를 구분한다.
- 단일 클라이언트의 다중 이벤트 학습은 의미 정렬 검증에 사용할 수 있지만 연합학습 SOTA의 증거로 취급하지 않는다.
- 현재 코드 변경이나 장시간 학습은 수행하지 않는다. 이 결정은 성능 달성 판정 또는 특정 후보 구현 완료를 의미하지 않는다.

## 이유

PEL의 세부 이벤트 구분 효과를 판단하려면 서로 다른 이벤트를 담은 시각 데이터와 대응 텍스트가 필요하다. 현재 손실은 실제 배치의 라벨에 해당하는 텍스트만 대조 행렬에 넣으므로 event dictionary 확장만으로 전체 후보를 사용하지 않는다. 이 조건을 먼저 확인한 뒤 구현과 실험을 설계하는 것이 타당하다.
