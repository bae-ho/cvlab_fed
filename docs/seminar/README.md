# 세미나용 지식 노트

설계·분석·실험에서 얻은 지식을 발표에 재사용할 수 있도록 주제별 Markdown으로 보관한다. 아키텍처·흐름은 Mermaid, 수식은 LaTeX, 중요 개념은 bullet point로 작성한다.

[지식 기록 스킬](../../.agents/skills/write-seminar-notes/SKILL.md)을 적용한다. 기본 파일명은 YYYY-MM-DD_주제.md이며 날짜는 기록일이다. 실험일·분석 기준일은 본문에서 구분한다. 현행 설계와 연구 근거는 원본 문서를 연결하고 관찰·가설·제안을 구분한다.
