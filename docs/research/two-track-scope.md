# 두 연구 트랙과 현재 PEL 작업 범위

- 날짜: 2026-10-06
- 근거: 사용자의 담당 범위 및 실험 맥락 명시. 과거 회의의 후보와 Slack 결과보다 현재 작업 경계를 우선한다.
- 현행 성능 목표: [프로젝트 정의](../README.md#현행-연구-목표와-성능-정의).

## 담당과 통합 시점
| 트랙 | 담당 | 현재 연구 내용 | 현재 어시스턴트 작업과 관계 |
| --- | --- | --- | --- |
| 집계 개선 | 장기태 연구원 | Fed-WSVAD 가중치 합산 방식을 수정해 성능 향상. 관련 서버 optimizer·개인화 조합 실험도 보고됨 | 독립 연구를 보존한다. 현재 PEL 작업에서 이 트랙의 집계 구현·설정을 수정하지 않는다 |
| PEL 적용 | 김배호 연구원, 사용자 지원 | Fed-WSVAD의 CCTV 적용 실험 및 PEL4VAD 방법론 결합으로 성능 향상 | 적용 모듈 위치와 데이터·손실·gradient 경로를 재검토하고 더 적절한 실험을 설계한다 |

두 트랙은 현재 각자 실험 중이다. 나중에 각 트랙에서 가장 좋은 방법을 확인한 뒤 통합한다. 지금 특정 집계 방식이나 두 트랙 결합을 최종 채택한 상태가 아니다. 과거 FedPGP 중심 합의와 FedNova 보고를 현재 PEL 작업의 집계 변경 지시로 해석하지 않는다.

## 현재 변경 경계
- PEL 방법론의 적용점, 시각/텍스트 특징, 손실, gradient, 유효 길이, 실제 대조 후보, 평가 및 데이터 구성을 조사하고 개선 설계를 한다.
- 집계 수식, 평균 가중치, 서버 업데이트/optimizer, 공유·로컬 정책, 참여 클라이언트 규칙을 PEL 개선을 이유로 바꾸지 않는다. 기존 기준 설정을 명시하고 유지한다.
- fed/ 파일 전체를 수정 금지하는 경계는 아니다. 향후 승인된 PEL 구현에서 클라이언트 손실·보조 출력 전달처럼 필요한 부분은 다룰 수 있지만 집계 트랙의 동작과 상태를 보존한다.
- 기본 FedAvg 경로의 PEL 옵션 미전달은 PEL 연결 문제로 취급한다. 다른 집계 방식으로 바꾸어 우회하지 않고 집계 동작을 유지하는 전달 경로 개선을 검토한다.
- 집계 문제를 발견하면 근거와 PEL에 주는 영향을 기록한다. 장기태 연구원의 실험·코드·설정을 덮어쓰지 않는다.
- 두 트랙 통합 구현이나 통합 실험은 후속 작업이다. 현재 문서화 요청만으로 학습이나 구현을 시작하지 않는다.

## 지자체 클라이언트와 scene/event 분할
지자체가 각 클라이언트라는 연구 맥락에서 Fed-WSVAD 실험은 scene split과 event split을 모두 적용해왔다. 두 분할은 지자체별 도메인과 사건 분포를 살펴보는 실험 조건이며 실제 지자체 데이터의 완전한 재현이라고 단정하지 않는다.

| 분할 | PEL 검토 시 핵심 | 보존할 조건 |
| --- | --- | --- |
| event | 각 로컬의 이상 클래스가 하나일 수 있다. 전체 클래스 dictionary가 있어도 로컬 배치의 이벤트 간 대조는 자동으로 생기지 않는다 | event 분할을 그대로 두고 가능한 의미 감독을 설계한다. 전체 클래스 텍스트 기준 등을 쓰면 원본과 다른 손실 변형임을 표시한다 |
| scene | 로컬에 여러 사건이 있을 수 있지만 실제 클래스 분포와 배치 구성은 확인이 필요하다 | 장면·카메라/세션 기준 분할, 라벨 인덱스, Normal 표본, 실제 대조 후보와 클래스 편중을 확인한다 |

PEL에 다중 이벤트가 필요하다는 이유만으로 클라이언트 영상 데이터를 합치거나 event를 scene/random으로 바꾸지 않는다. 다중 이벤트 단일 로컬 실험은 방법론 진단용 별도 실험으로 표시하며 event 연합 실험 결과를 대체하지 않는다. 기준과 PEL 후보는 같은 분할·집계·초기화·학습 예산에서 비교한다.

현재 CCTV 전처리와 loader는 event 6클래스만 준비되어 있고 scene 메타데이터는 없다. scene까지 이미 구현됐다고 쓰거나 event 자료를 이름만 바꿔 scene으로 사용하지 않는다. 추후 CCTV scene 실험에는 신뢰할 수 있는 장면/관제 단위 식별과 누수 없는 분할 준비가 필요하다.

## 향후 통합을 위한 인터페이스
- 공유 파라미터와 로컬 상태의 의미·key/shape, 글로벌 배포 동작을 기록한다. PEL이 새 상태를 추가하면 기존 정책을 임의 변경하지 않고 영향과 설계 선택을 명시한다.
- 글로벌 평가에서 개인화 adapter를 끄는 조건을 고려해 PEL의 개선 gradient가 공유 검출 경로에 전달되는지 확인한다.
- 반환하는 가중치·집계 가중치의 단위·local step 집계 규약을 PEL 변경으로 바꾸지 않는다.
- scene/event 각각에서 특징 추출기, 라벨/텍스트 매핑, 유효 길이, 대조 후보, 업데이트 범위와 평가 정책을 기록한다.
- 이후 통합 단계에서는 기준, 집계 개선만, PEL만, 둘의 결합을 같은 분할과 예산에서 비교해 각각의 효과와 상호작용을 확인한다. 이는 향후 계획이며 현재 실행 범위가 아니다.

## 현재 재실험의 고정 기준

2026-10-06 사용자는 김배호 트랙의 재실험에서 Fed-WSVAD 기본 FedAvg를 지정했다. 서버 optimizer와 개인화는 none으로 두고 기존 집계 가중치·반환 규약을 유지한다. 전체 이벤트의 고정 텍스트 기준과 PEL-only 시각 gradient를 적용한 뒤 같은 조건의 기본 모델과 비교한다. 구체적인 변경과 미구현 상태는 [수정 계획](../plans/active/2026-10-06-fedavg-fixed-anchor-pel.md)을 따른다.
