# 회의 자료와 현행 목표의 관계

이 디렉터리의 PDF는 당시 논의와 제안 내용을 보존한다. 현재 연구 목표와 성능 정의는 [프로젝트 지식 지도](../README.md#현행-연구-목표와-성능-정의)에서 관리한다.

| 자료 | 관련 내용 | 현행 적용 |
| --- | --- | --- |
| [2026년 8월 14일 회의록](2026-08-14%20회의록.pdf) | 로컬 PEL 결합, FedPGP, 신종 이상 탐지, 단일 로컬 검증 논의 | 결합 논의의 배경. 신종 이상 검증은 현재 필수 범위에서 제외 |
| [2026년 8월 28일 회의록](2026-08-28%20회의록.pdf) | 이전 결정 요약과 대조학습 목적 | 동일하게 현행 목표 정의를 우선 적용 |
| [과제 제안서](지자체%20프라이버시%20보호형%20연합학습%28CLAP%29%20기반%20VLM을%20통한%20신종%20이상%20행동%20실시간%20탐지%20시스템%20개발%20및%20실증%20제안서.pdf) | zero-shot 신종 이상 탐지와 실증의 상위 구상 | 역사적 제안 내용. 현재 저장소 작업의 성능 성공 기준은 현행 문서에서 정의 |

2026-10-06 사용자 지시로 현재 성능 목표가 갱신되었다. 원본 PDF를 소급 수정하지 않고 [결정 기록](../decisions/0002-vad-performance-objective.md)에 변경 이유와 영향을 남긴다. 과거 회의 자료에 나온 후보의 명칭이나 요약만으로 실제 코드에 그 방법이 구현됐다고 판단하지 않는다.

## Slack 추가 보고와 현재 경계
[Slack PDF](slack-experiments-log.pdf)는 8/31, 9/11, 10/2 보고와 날짜 미표기 통합표를 포함한다. [근거 대조](../research/slack-experiment-evidence.md)에서 설정·수치 차이를 관리한다. 현재는 [두 독립 트랙](../research/two-track-scope.md)으로 실험 중이며 집계 보고는 PEL 작업의 집계 변경 권한이 아니다.
