## 논문 용어와 구현 식별자

Fed-WSVAD 논문은 multiple instance learning (MIL)으로 영상 단위 예측을 얻고, 영상 라벨에 대한 분류 손실을 정의한다. 논문 식 (3)의 로컬 목적은 $L_i=-\mathbb{E}_{(v,Y)\in D_i}Y\log P$이다. 문서에서는 이를 **MIL 기반 분류 손실**로 설명한다. 이는 논문에서 정의한 연산을 설명하는 표현이며 별도의 새 손실 이름이나 공식 약어를 제안하는 것이 아니다.

- $i$: 클라이언트 인덱스
- $D_i$: 클라이언트의 로컬 데이터
- $v$: 입력 영상
- $Y$: 영상 단위 클래스 라벨
- $P$: MIL로 얻은 영상 단위 다중 클래스 예측 확률
- $L_i$: 클라이언트의 분류 손실

공식 저장소 `utils/tools.py`의 함수명은 `CLASM`이다. 자체적으로 만든 약어는 아니지만 논문의 공식 방법론 명칭은 아니다. 코드 탐색·실제 함수 호출 설명에서만 이 식별자를 사용한다. 실제 연산은 유효 길이 내 클래스별 top-k logits 평균과 영상 라벨의 softmax cross entropy이다.

## 문서 적용

- 본문·표·Mermaid: MIL 기반 분류 손실
- 수식의 설명용 기호: $\mathcal{L}_{\mathrm{MIL}}$; 논문 원식의 $L_i$와 구분한 프로젝트 표기
- PEL 결합 설명: MIL 기반 분류 손실 + 가중 PEL 의미 정렬 손실
- 소스 함수·기존 JSON 키·원시 로그: 실행 호환성과 근거 보존을 위해 유지
- 기존 실험 수치·조건: 용어 정정과 무관하게 보존
