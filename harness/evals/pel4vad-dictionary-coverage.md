# PEL 이벤트 사전과 대조 후보 해석

- 사례 ID: pel4vad-dictionary-coverage
- 관련 실패 또는 작업: 최초 설명에서 dictionary 확장과 실제 대조 후보 구성을 충분히 구분하지 못한 점을 후속 분석에서 정정함.

## 목적

이벤트 수, 클래스별 지식 표현 수와 손실의 실제 대조 후보를 구분하여 문서 및 개선 제안의 정확성을 확인한다.

## 사전 조건과 입력

- 현재 `scripts/experiment_pel4vad_client.py`, `utils/tools.py`, `fed/client.py`.
- 공식 PEL4VAD의 `dataset.py`, `utils.py`, `train.py`.
- 요청: 한 이벤트와 Normal 실험에서 사전 및 시각 이벤트를 늘리면 성능 향상 가능성이 있는지 판단.

## 수행할 작업

dictionary 생성부터 class index 선택, token stacking과 similarity matrix까지 추적한다. 단일 이벤트 배치와 다중 이벤트 배치의 차이를 설명하고 현행 연구 목표를 확인한다.

## 성공 기준

- [x] 원본의 샘플별 텍스트 두 개와 배치별 다중 이벤트 후보 구성을 설명한다.
- [x] 현재 dictionary에 클래스 이름만 추가해도 모든 항목이 PEL 음성 후보가 되지는 않는다고 명시한다.
- [x] 다중 이벤트의 실제 학습 데이터 추가와 지식 기반 텍스트 확장을 구분한다.
- [x] 기존 단일 실험의 이벤트 인덱스 1 고정이 다중 이벤트 수정 대상임을 설명한다.
- [x] 성능 향상 가능성을 달성 사실로 표현하지 않는다.
- [x] 미학습 이벤트 검증을 현재 필수 성공 기준으로 재도입하지 않는다.

## 실패 조건

- 사전 문자열 수만으로 대조 후보 수를 단정한다.
- 원본 PEL이 매 배치에 항상 전체 클래스 텍스트를 사용하는 것으로 설명한다.
- 단일 클라이언트 또는 CCTV 자체 결과만으로 연합학습 SOTA를 주장한다.
